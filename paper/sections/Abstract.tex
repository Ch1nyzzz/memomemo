Automated harness optimization improves an agent harness---the code that
determines what to store, retrieve, and present to a model---through an
iterative propose--evaluate loop. Recent systems such as Meta-Harness replace
compressed textual feedback with a coding agent that can inspect the full
filesystem history of prior candidates, allowing the proposer to diagnose
failures from raw code, traces, and diffs. However, full access is not the same
as useful access: as the optimization horizon grows, the expanding history can
dilute the proposer's attention, forcing it to repeatedly rediscover which past
runs and files are relevant to the next edit.We formulate this bottleneck as an \emph{online context curation} problem. At each iteration, before observing the next candidate's reward, the optimizer must choose an evidence bundle for the proposer under a limited attention budget: which prior iterations to expose, how much trace detail to include, and which
workspace files to emphasize. We introduce \name, a framework that treats this
choice as a first-class control variable in automated harness optimization.
\name curates proposer context along two complementary axes. Along the
\emph{iteration axis}, a adaptive policy starts from narrow evidence
around the best/worst prior pair and escalates to richer history only after
optimization stalls. Along the \emph{file axis}, a bandit policy assigns delayed
credit to files read by the proposer and concentrates future attention on files
whose inspection has historically led to productive edits.Across three benchmarks spanning agentic software engineering and long-horizon
memory, \name improves over the uncurated full-context baseline in most
(benchmark, proposer) settings, with the largest gain raising SWE-bench
Verified passrate by up to 20 points over the source harness. Trajectory-level
analysis shows that most training-time improvements arise from low- or
medium-budget iterations rather than full-context ones, demonstrating that
proposer context is not merely an implementation detail or a static prompt
artifact, but an online optimization variable that determines how effectively
the harness search progresses.
