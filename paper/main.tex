\begin{abstract}
Recent work has shown that coding agents can optimize LLM agent scaffolds
through a propose--evaluate loop, but leaves the proposer's attention
unmanaged: every iteration sees the full file tree and complete execution
history with no explicit optimization direction.  We present Optimization
Harness, a modular framework that curates the proposer's context and
guides which mechanism axes it explores.  The framework provides Docker
file-scope sandboxing, mechanism-level optimization-focus prompts, and
labeled best/worst reference iterations, enabling two adaptive
context-selection policies.  The progressive policy runs a budget state
machine (\texttt{low}$\,\to\,$\texttt{medium}$\,\to\,$\texttt{high})
that escalates only after a Pareto-frontier stall and resets on every
improvement; the bandit policy scores every readable file with a
per-file UCB scorer, rolling $z$-score reward, and Beta-smoothed prior,
concentrating high-utility files in a hot workspace each iteration.
Across three benchmarks and two proposer families, gradual context
disclosure consistently outperforms both fixed-high and fixed-low
baselines: on LoCoMo the adaptive policies improve test passrate by up
to +5\,pp; on LongMemEval progressive reaches 0.500 (+3\,pp); a
bandit-discovered scaffold raises SWE-bench Verified from 0.44 to 0.64
(+20\,pp) on the full 500-task split; and on Codex GPT-5.4 the bandit
halves proposer-input cost with no test regression. Of 48 score-improvement events across ten runs, 35 occur at \texttt{low} or
\texttt{medium} budget, and the per-opportunity breakthrough rate at
\texttt{high} does not exceed that of the lower tiers---curating what an
optimizer attends to beats giving it more context.
\end{abstract}
